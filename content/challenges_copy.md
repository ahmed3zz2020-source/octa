# نصوص «تحدي اليوم» + لوحة المتصدرين — باقة «نماذجي»

> **ملف مرجعي للنصوص.** كل بلوك = عنصر واحد في الواجهة.
> النص المكتوب بين الكود المربع هو النص الجاهز للنسخ كما هو، من غير أي تعديل.
>
> **القواعد المطبّقة:**
>
> - أرقام عربية (٠١٢٣٤٥٦٧٨٩).
> - كل كلمة لاتينية جوّه جملة عربية في أقواس.
> - جملة واحدة = فكرة واحدة.
> - سطر قصير ينفع يتحط في كارت.
> - بدون مبالغة ولا ادعاء دقة.
>
> **الترتيب:** ① السؤال · ② الشرح · ③ النتيجة · ④ المتصدرون · ⑤ إحصاءاتك · ⑥ التنبيه · ⑦ ملاحظات (مش للنسخ).

---

## ① صياغة السؤال (٣ صيغ تتبدّل)

السؤال بيظهر في كارت التحدي، تحت المستوى اللي فوق.
الصيغة الأساسية هي الافتراضية، والتانية والثالثة بدائل بتتبدّل مع تحديات الأيام الجاية.

**صيغة ١ — الأساسية (الافتراضية):**

```
خلال ١٠ جلسات: هل يوصل السعر للهدف قبل ما يلمس الوقف؟
```

**صيغة ٢ — أقصر:**

```
هدف ولا وقف — أيهم ييجي الأول خلال ١٠ جلسات؟
```

**صيغة ٣ — بالتسمية الكاملة:**

```
في ١٠ جلسات: هل يتحقق المستوى الهدف قبل المستوى الوقف؟
```

**سطر توضيح تحت السؤال (يوضّح زرارين التصويت):**

```
صعود = يوصل للهدف قبل الوقف · هبوط = يلمس الوقف قبل الهدف
```

---

## ② الشرح والمستويات

### ٢.a — شرح صفحة التحدي (٦ جمل، بالترتيب)

**سطر ١ — إيه هو التحدي:**

```
تحدي اليوم سؤال واحد على سهم واحد، بيتبدل كل يوم.
```

**سطر ٢ — إزاي بيتحسب:**

```
محرك OCTA بيختار السهم ويحسب ٣ مستويات: دخول ووقف وهدف.
```

**سطر ٣ — إيه اللي بيتميّزه:**

```
المستويات دي متحسبة من شموع يومية حقيقية، مش من تخمين.
```

**سطر ٤ — إزاي بتصوّت والنتيجة بتظهر:**

```
أنت بتصوّت صعود أو هبوط، والنتيجة بتظهر بعد ١٠ جلسات من شموع السوق نفسها.
```

**سطر ٥ — الهدف مستوى مش وعد:**

```
⛔ الهدف مش وعد بسعر — هو مستوى بيتحسب من شموع اليوم السابق.
```

**سطر ٦ — إيه اللي مش بيقوله:**

```
⛔ التحدي بيقيس قرارك في قراءة المستويات، مش بيوصّلك لصفقة.
```

### ٢.b — «⚠️ الأرقام دي مش بتقول إيه» (٣ سطور)

```
⛔ مفيش دقة متوقعة ولا ضمان — كل تحدي حالة واحدة.
⛔ تصويتك مش رأي المحرك — هو قرارك أنت.
⛔ نتيجة تحدي قديم مش بتتكرر في تحدي جديد.
```

### ٢.c — تسميات المستويات (٣)

**دخول:**

```
إغلاق شمعة اليوم السابق. مش سعر النهارده.
```

**هدف:**

```
المستوى اللي لو اتلمس قبل الوقف، التحدي بينتهي بالصعود.
```

**وقف:**

```
المستوى اللي لو اتلمس قبل الهدف، التحدي بينتهي بالهبوط.
```

**سطر تحذير تحت شبكة المستويات:**

```
⚠️ الدخول والوقف والهدف أرقام متحسبة — مش وعد ولا ترشيحة سعر.
```

---

## ③ نصوص النتيجة (٣)

**عنوان النتيجة (لما تتحل):**

```
التصحيح
```

**النتيجة «صعود» — العنوان:**

```
صعود
```

**النتيجة «صعود» — سطر الشرح:**

```
وصل السعر للمستوى الهدف قبل ما يلمس المستوى الوقف.
```

**النتيجة «هبوط» — العنوان:**

```
هبوط
```

**النتيجة «هبوط» — سطر الشرح:**

```
لمس السعر المستوى الوقف قبل ما يوصل للمستوى الهدف.
```

**النتيجة «متعادل» — العنوان:**

```
متعادل
```

**النتيجة «متعادل» — سطر الشرح:**

```
مفيش مستوى اتلمس خلال ١٠ جلسات، أو الشمعة لمست الاتنين مع بعض.
```

**سبب النتيجة (سطر قصير جنب النتيجة):**

```
الشمعة لمست المستويين
```

```
مفيش لمس خلال ١٠ جلسات
```

**سطر التصحيح بعد ظهور النتيجة (بديل النصوص الحالية في الكود):**

```
إجابة صحيحة — +١ نقطة.
```

```
الإجابة كانت غلط — مفيش نقاط.
```

```
مفيش تصحيح — صوتك محسوب متعادل.
```

---

## ④ لوحة المتصدرين

**العنوان:**

```
🏆 لوحة المتصدرين
```

**سطر احتساب النقاط:**

```
كل إجابة صحيحة = ١ نقطة · الإجابة الغلط = ٠ · المتعادل = ٠.
```

**سطر قواعد الترتيب:**

```
عند تساوي النقاط: الدقة، ثم عدد الصحيحة، ثم الأقدم تسجيلاً.
```

**سطر سبب قفل اللوحة:**

```
اللوحة بتتقفل لحد ما ٣ مصوّتين على الأقل يسجّلوا — عشان ما تظهرش شبه فاضية.
```

**رسالة اللوحة المقفلة (لما الحالة مقفولة):**

```
🏆 لوحة المتصدرين هتفتح بعد ٣ مصوّتين
```

**سطر الخصوصية (النسخة المعتمدة — الباك بيقنّع الاسم: أول حرفين بس):**

```
الاسم في اللوحة مقنّع — جزء من الاسم بس، من غير بياناتك الكاملة.
```

> ⛔ لو الباك اتغيّر وبدأ يعرض أسماء عشوائية ⇒ السطر التاني اللي تحت
> (في ملاحظات المطور) هو البديل — مفيش ت/etc.
>
> ```
> الأسماء في اللوحة مستعارة وعشوائية — من غير بياناتك الكاملة.
> ```

**سطر ترتيب المستخدم:**

```
ترتيبك بين المصوّتين، بنفس قواعد الترتيب دي.
```

---

## ⑤ إحصاءاتك (٦ أرقام + المتعادل)

**النقاط:**

```
عدد إجاباتك الصحيحة. الإجابة الغلط ما بتاخدش خصم — صفر بس.
```

**صح:**

```
عدد التحديات اللي توقعت فيها صح.
```

**غلط:**

```
عدد التحديات اللي توقعت فيها غلط.
```

**متعادل:**

```
عدد التحديات اللي مفيش فيها نتيجة واضحة. دي مش بتتحسب عليك.
```

**الدقة:**

```
نسبة إجاباتك الصحيحة، محسوبة من التحديات اللي اتحلّت.
```

**السلسلة:**

```
عدد التحديات اللي توقعت فيها صح ورا بعض. أول غلط بيصفّرها.
```

**الترتيب:**

```
ترتيبك في لوحة المتصدرين.
```

**سطر توضيح الدقة (لما المستخدم يفتح التفاصيل):**

```
الدقة نسبتك أنت في التحديات اللي اتحلّت — مش دقة المحرك.
```

## ⑥ التنبيه (في آخر الصفحة)

> نفس نبرة صفحات OCTA الحالية: ⛔ + «مش توصية شراء أو بيع» + «القرار قرارك».

**نسخة كاملة (في آخر الصفحة):**

```
⛔ التحدي تمرين على قراءة المستويات، مش توصية شراء أو بيع.
⛔ الهدف مستوى بيتحسب، مش وعد بسعر. والقرار قرارك.
```

**نسخة قصيرة (جوّه الكارت):**

```
⛔ مش توصية شراء أو بيع — القرار قرارك.
```

## ⑦ ملاحظات خلفية (مش للنسخ في الواجهة)

**ربط النصوص بالحقول (للفريق التقني):**

| النص | الحقل في الرد |
|---|---|
| السؤال (①) | `challenge.question_ar` |
| الرمز والاسم والقطاع | `challenge.code` · `challenge.name` · `challenge.sector` |
| الدخول / الوقف / الهدف | `challenge.entry` · `challenge.stop` · `challenge.target` |
| الاتجاه | `challenge.direction` |
| الأفق (١٠ جلسات) | ثابت في النص — مش حقل منفصل |
| صوتك | `challenge.my_vote` |
| النتيجة | `challenge.resolved.outcome` |
| سبب النتيجة | `challenge.resolved.reason` |
| النقاط · صح · غلط | `me.points` · `me.correct` · `me.wrong` |
| متعادل · الدقة · السلسلة · الترتيب | `me.neutral` · `me.accuracy` · `me.streak` · `me.rank` |
| صفوف المتصدرين | `rows[]` — الاسم `alias` · `points` · `correct` · `accuracy` · `streak` |

**⛔ تعارض الأسماء المستعارة — لازم يتصلّح:**

- الكود بيقول «الأسماء المستعارة عشوائية».
- ومواصفة الباك بتقول إن الاسم **مقنّع** (أول حرفين + «…»).
- النصين متناقضين، والصح هو اللي الباك بيعمله فعلاً.
- لو الباك بيقنّع ⇒ النسخة الأولى في ④ هي الصح.
- لو الأسماء عشوائية ⇒ النسخة التانية في ④ هي الصح.
- في الحالتين: **ممنوع** يظهر أي بريد أو معرّف.
- ⛔ سطر الخصوصية في ④ بيتصوَّف كوعد **غير مشروط** — وده اللي اتصلّح.
- ⛔ «من غير بياناتك الكاملة» أأمن من «من غير أي بيانات شخصية».
- ⛔ النسخة المستعملة في كود الواجهة: «من غير بياناتك الكاملة».

**⛔ السؤال الاحتياطي في الكود:**

- في الكود سؤال احتياطي لما `question_ar` يبقى فاضي.
- وهو عن كسر صعودي ودولار — مش عن آلية الهدف والوقف.
- **لازم يتبدّل بواحد من صيغ ①** — الأساسية هي الأنسب.

**⛔ مقام «الدقة» محتاج تأكيد:**

- سطر الدقة في ⑤ بيقول «من التحديات اللي اتحلّت».
- لو الباك بيحسب `correct ÷ (correct + wrong)` ⇒ المتعادل مش في المقام.
- والسطر يتعدّل لـ«من إجاباتك المحسومة».
- **ممنوع أكتبله معادلة قبل ما الباك يتأكد.**
- الواجهة بتاخد الرقم جاهز من `me.accuracy` في كل الأحوال.

**الاستخدام آمن في الاتجاهين:**

- نصوص ① و② و③ مكتوبة بالمستويات (هدف ووقف) مش بحركة السعر.
- بتشتغل سواء التحدي صاعد أو هابط.
- لو التحدي هابط، الهدف تحت الدخول والوقف فوقه.
- والجمل نفسها تفتح من غير تعديل.

**الترتيب (من قواعد الباك):**

- نقاط تنازلي · ثم الدقة تنازلي · ثم عدد الصحيحة تنازلي.
- ثم الأقدم تسجيلاً.
- سطر ④ مكتوب على نفس الترتيب بالظبط.

**قفل اللوحة تحت ٣ مصوّتين:**

- السبب إن اللوحة شبه فاضية بتبان كأنها الميزة معطّلة.
- فقفلها أوضح من عرض صف واحد.
- سطر ④ بيقول السبب من غير ما يوعد بتاريخ فتح.

**«مستوى» مش «وعد»:**

- سطر ② وسطر ⑤ بيوصّوا إن الهدف **مستوى بيتحسب**.
- أي نص جديد عن الهدف لازم يلتزم نفس الصياغة.
- وممنوع أي كلمة توعد بسعر (زي «هيوصل» أو «مستهدف»).

**سبب قصر الأسئلة:**

- صيغ السؤال من ٧ إلى ١١ كلمة.
- عشان تبان في كارت واحد على موبايل من غير لف.
