## 🏗️ المكوّنات (٦ ملفات)

### ① `AGENTS.md` — عقد العمل (الأهم)
أول ملف بيقراه أي مساعد. فيه:
- مين المشروع، إيه الهدف، إيه اللي **مش** بنعمله
- قوانين النشر (preview → اختبار → موافقة → prod)
- الـstack التقني
- الأوامر المهمة (sync, test, build, deploy)
- **«متعملش كده»** — القائمة accumulated من الأخطاء اللي اتوقعنا فيها

**~٣٠٠ سطر**

### ② `ARCHITECTURE.md` — خريطة النظام
- كل الملفات الرئيسية ووظيفة كل واحد
- تدفّق البيانات (من فين → فين)
- الـAPI endpoints والـdata flow
- المعمارية: `tv-shim.js` كمصدر واحد للشارت

**~٤٠٠ سطر**

### ③ `DOMAINS.md` — المعرفة التقنية
- محرك التقييم: ٧ محاور + الأوزان + المعادلات
- منطق التوصيات (`ORDER` صحيح)
- قوانين السوق المصري (MO5، lot size، الفريمات)
- مصادر البيانات وحدودها
- **blokirs معروفة** (شِلات، hard-coded،_ToS)

**~٣٠٠ سطر**

### ④ `DECISIONS.md** — سجل القرارات (الأعلى قيمة)
كل قرار: التاريخ · السياق · الخيارات · القرار · السبب
مثال:
> **٢٠ أكتوبر: صياغة رسالة تيليجرام**
> السبب: `parse_mode=HTML` كان ناقص فظهر `<b>` كنص · القرار: أضفنا + شريط 🟩 + أرقام عربية

**~٥٠٠ سطر وبيكبر**

### ⑤ `SESSION-NOTES.md** — يوميات العمل
كل جلسة: إيه اتعمل، إيه اتعلّم، إيه اتأخر، الخطوة الجاية
آخر ٣٠ يوم — بيلفّ أوتارشيفي أول كل شهر

**~١٠٠ سطر**

### ⑥ `assets/js/CONTEXT.md` — للموقع نفسه
مش مطلوب — ده ملف خارج
