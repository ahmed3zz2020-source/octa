## ① الـ405 على ٤ طلبات — السبب الحقيقي

**الظاهرة:** ٤ × `405 Method Not Allowed` + body:
```html
<title>405 Method Not Allowed</title>
```

**الـURL بالظبط** (من الـconsole، مش تخمين):
```
GET https://octa-prices-production-4ccb.up.railway.app/api/v1/quote?symbol=OANDA:XAUUSD
GET https://octa-prices-production-4ccb.up.railway.app/api/v1/quote?symbol=EGP:X
GET https://octa-prices-production-4ccb.up.railway.app/api/v1/quote?symbol=EGX:EGX30
GET https://octa-prices-production-4ccb.up.railway.app/api/v1/quote?symbol=TVC:USOIL
```

**السبب الجذري — `assets/js/octa-api.js`:**
```js
// ❌ الكود القديم: كان بيختبر المسار بـ indexOf('/api/')
function _isOurs(url) { ... if (u.origin === location.origin) ... }
```
`https://www.tradingview-widget.com/api/v1/quote` — فيه `/api/`!
⇒ اتعامل كأنه نداء داخلي ⇒ اتحوّل لـRailway ⇒Railway مالوش المسار ده ⇒ **405**.

**✅ الحل (موجود في `c68f577` — كان مش منشور!):**
```js
function _isOurs(url) {
  if (s.charAt(0) === '/') return true;          // نسبي ⇒ بتاعنا
  const u = new URL(s);
  if (u.origin === location.origin) return true;  // نفس الأصل
  if (d && u.href.indexOf(d) === 0) return true;  // السيرفر المباشر
  return false;                                    // ⛔ الباقي خارجي
}
```
**📌 درس:** ⛔ ما تديرش `indexOf('/api/')` على URL كامل — دايماً قارن **الأصل**.

## ⑥ 🐛 bug إضافي اتكشف: جسر الشموع

`/api/tvcandles?code=COMI.CA` ⇒ **502 "no data"** — من أول نسخة من الجسر!

**السبب** (`worker.js:379`):
```js
// ❌ الكود القديم
const code = (...).toUpperCase().replace(/[^A-Z0-9]/g, '');
// ⇒ "COMI.CA" بقى "COMICA" ⇒ startamarkets ملقاش الرمز ⇒ [] ⇒ 502
```

```js
const rawCode = (...).toUpperCase().replace(/[^A-Z0-9.]/g, '');  // النقطة مسموحة
const code = rawCode.replace(/\.CA$/, '');                        // ونشيل .CA
```
⇒ `COMI.CA` → `COMI` ⇒ ٥٠٠٠+ شمعة ✅
