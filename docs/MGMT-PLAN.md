# 📊 OCTA — خطة شات الإدارة (OCTA-Management)

> التاريخ: ٢٠ أكتوبر ٢٠٢٦
> الحالة: **خطة.** مفيش حاجة اتنفّذت لسه.
> الهدف: شات متخصص يقرأ داتا الموقع ويطلع تقارير مفيدة تُبنى عليها قرارات.

---

## 🔴 الفجوة اللي اكتشفتها دلوقتي

حالياً التتبع **شغّال بس ضعيف جداً:**

| الحدث | العدد في الكود |
|---|---:|
| `page_view` | ١ |
| `signup` | ١ |
| `signup_start` | ١ |

**مفيش تتبّع:**
❌ فلاتر ولا أدوات ولا شارت
❌ ولا كارت قرار ولاRealview
❌ ولا أزرار (بحث · تيل ·Gold)
❌ ولا وقت الجوسة الفعلي

**النتيجة:** `top_actions` في التقرير بيرجع فاضي أو شبه فاضي.
**يعني التقرير هيكون ناقص من أهم صورة فيه.**

---

## 💡 اللي نعمله: ٤ مراحل

### 🅰️ المرحلة ١ —Audit (نعمله دلوقتي، بدون كود)

أعمل تقرير **يدوي** من الـendpoint الموجود `/api/admin/monthly` وأقولك:
- كام مستخدم
- كام نشط
- إيه أكتر صفحة
- إيه اللي ناقص في الداتا

**⏱️ ١٠ دقايق**

---

### 🅱️ المرحلة ٢ — تقوية التتبع (كود)

**نضيف تتبّع للفلاتر والأدوات الأساسية:**

```javascript
octaTrack('filter_use', 'screener', 'P/E < 15')      // الفلتر
octaTrack('tool_open', 'sidebar', 'Realview')          // الأداة
octaTrack('chart_open', 'modal', 'COMI')               // الشارت
octaTrack('decide_view', 'stock', 'COMI')              // كارت القرار
octaTrack('search', 'header', 'COMI')                  // البحث
```

**الداتا الجديدة اللي هتاخد:**
- أكتر فلتر بيتستخدم → نطوّره الأول
- أكتر أداة بتتفتح → دي价قيمة的
- أكتر سهم بيتحليل → نخصص له
- مسار المستخدم: بيدخل إيه → بيعمل إيه → بيسيب إيه

**⏱️ ساعة واحدة**

---

### 🅲️ المرحلة ٣ — لوحة HTML تفاعلية (الأساسي)

**الملف:** `admin/index.html` — صفحة واحدة، تشتغل في المتصفح.

**ليها layout من ٤ أقسام:**

```

│  header: تاريخ آخر تحديث · زر refresh           │
├──────────────────────────────────────────────────┤
│  ٤ كروت كبيرة (أرقام سريعة)                    │
│  إجمالي المستخدمين · نشط ٧ أيام · جدد ٣٠ يوم ·  │
│  نسبة الرجوع                                     │
├──────────────────────────────────────────────────┤
│  ٢ قسم جنب بعض                                  │

├──────────────────────────────────────────────────┤
│  جدول المستخدمين: الاسم · الميلاد · زيارات ·    │
```

**⏱️ ٣-٤ ساعات**

---

### 🅳 المرحلة ٤ — التقرير الشهري (الشرط بيكمل لوحده)

**file** `admin/MONTHLY-REPORT.md` — بيتجدّد بـسطر أو ٢ كل أسبوع.

**هيكل التقرير:**

```
١. ملخص تنفيذي (٥ أسطر)
٢. النمو: كم مستخدم جديد · نسبة الرجوع
٣. الاستخدام: أكتر صفحة · أكتر أداة · أكتر فلتر
٤. السلوك: مدة الجوسة · عمق التصفح · المستخدمين اللي رجعوا
٥. 🔔 الأرقام اللي بتقولنا نعمل إيه
٦. ❌ الأرقام اللي مش مهمة (نستبعدها من التقرير)
```

---

## 🎯 القسم الأهم: «الأرقام اللي بتقولنا نعمل إيه»

دي التقرير الحقيقي. **مش وصف — ده قرار.**

**أمثلة على الأسئلة اللي التقرير لازم يجاوبها:**

| السؤال | الرقم اللي بيحسمه |
|---|---|
| نطوّر أنهي فلتر الأول؟ | أكتر فلتر بيتنخدم |
| أنهي صفحة مهملها؟ | صفحات عليها زيارات |
| ليه نعتبره نشط؟ | نسبة الرجوع (active_7d ÷ active_30d) |
| الموقع بيحتاج شرح؟ | مدة الجوسة القصيرة |
| أنهي أداة تستحق تحسين؟ | الأدوات كتير فتح + قليل استخدام |

---

## 📊 القسم الثاني: «اللي مش مهم»

عشان التقرير ميبقاش ضجيج.

**نستبعد:**
❌ أنسب التقاطعات-Аرقام بتفرق أقل من ٥٪
❌ أكتر صفحة تفتحاً لو الناس بتسيب فوراً
❌ تكث يفصّو في بيانات فردية (خصوصية)
