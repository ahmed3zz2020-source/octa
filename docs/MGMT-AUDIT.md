### 🔎 قراءة الجدول

ده bug في القياس، مش في المستخدم.

لازم يتحذف قبل أي تقرير رسمي.

## 🔨 المطلوب في Stage ٢ (تقوية التتبع)

**السبب:** من غير ده، كل تقرير بعد ده هيبقى عن «الصفحات» بس، مش عن «السلوك».

```javascript
// الفلاتر
octaTrack('filter_use', 'screener', 'pe<15')

// الأدوات
octaTrack('tool_open', 'sidebar', 'realview')

// الشارت
octaTrack('chart_open', 'modal', 'COMI')

// كارت القرار
octaTrack('decide_view', 'stock', 'COMI')

// البحث
octaTrack('search', 'header', 'COMI')

//ريفيو وذهب / توزيعات
octaTrack('tool_open', 'sidebar', 'gold')
octaTrack('view', 'dividends', '')
```

**اللي هينفع نعرفه بعدها:**
- أكتر فلتر بيتستخدم → نطوّره الأول
- أكتر أداة بتتفتح → دي قيمية
- مسار المستخدم الحقيقي: بيدخل إيه → بيعمل إيه → بيسيب إيه
- هل الأدوات الـ8 بتُستعمل ولا ٣ بس؟
