# 🧪 التجربة قبل النشر

> آخر تحديث: 12 أكتوبر 2026

---

## 🎯 **الفكرة**

```
عدّل على جهازك
    ↓
شوف على localhost
    ↓
خلاص نتأكد
    ↓
انشر على الدومين
```

**الدومين مش هيتلمس غير لما انت تقول** ✅

---

## 🚀 **التشغيل**

```bash
cd /workspace/octa5
./TEST-LOCAL.sh
```

**هيفتح على:**

```
http://localhost:8080
```

---

## 📱 **من الموبايل (نفس الشبكة)**

```
http://192.168.x.x:8080
```

**الرقم بيظهر في اللوج أول ما تشغّل**

**البوابة مش هتفتح** —因為 localhost check

**بس:** الموقع هيفتح على الموبايل

## ⏹️ **الإيقاف**

```
Ctrl + C
```

---

## 🔥 **ليه دلوقتي بالذات؟**

```
أنت قلت: مش عاوزه في الدومين إلا لما أختبر
```

**ده بالظبط اللي بيعمله السكربت:**

```
❌ ما يعملش deploy
❌ ما يمسّش الدومين
❌ ما يعملش git push
✅ بيشغّل نسخة محلية بس
```

---

## 📋 **القاعدة من دلوقتي**

| الخطوة | الأمر |
|---|---|
| **تعديل** | عدّل الملفات عادي |
| **اختبار** | `./TEST-LOCAL.sh` |
| **لو تمام** | `npm run build && git push && wrangler deploy` |
| **لو مش تمام** | عدّل تاني، ما تنشرش |
