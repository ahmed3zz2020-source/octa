# OCTA V2 — أول مسار (نسخة معزولة)

> ⛔ **هذه نسخة تجريبية معزولة تمامًا.** لا تتصل بخدمة أسعار الإنتاج ولا بتسجيل دخول أوكتا
> ولا بالتخزين ولا بتيليجرام. كل الأرقام هنا مُصنَّعة داخل الحزمة.

## التشغيل المحلي

```bash
git clone https://github.com/ahmed3zz2020-source/octa.git
cd octa && git checkout feat/v2-first-path

# ① فحص العزل الثابت (يرفض أي ارتباط بالإنتاج)
npm run v2:check

# ② تشغيل الواجهة محليًا ⇒ http://127.0.0.1:8099/
npm run v2:serve

# ③ اختبار المسار كاملًا (موبايل ٣٦٠ + كمبيوتر) ⇒ صور + تقرير
python3 v2/tests/test_v2.py
```

## بنية المسار الأول

| الشاشة | المسار | المحتوى |
|---|---|---|
| السوق | `#/market` | ٤ مؤشرات + قائمة أسهم تجريبية + مصدر البيانات وتوقيته |
| السهم | `#/stock/MOCK1` | السعر + الشارت (SVG) + مصدر البيانات + التوقيت +cases الناقصة |
| المقارنة | `#/compare` | حتى ٣ أسهم جنبًا إلى جنب + منع الرابع |

### حالات البيانات (كلها ظاهرة في الواجهة)

| الحالة | كيف تُستدعى | ما يظهر |
|---|---|---|
| تحميل | `index.html?slow=1` | هيكل عظمي (skeleton) متحرك |
| بيانات ناقصة | `#/stock/MOCK6` | «غير متاح» بدل قيمة مفترضة + توضيح |
| خطأ | `#/stock/MOCK5` | رسالة خطأ + زر «إعادة المحاولة» |

## فصل عقد البيانات عن الإنتاج

```
v2/assets/js/v2-contract.js      ← العقد (أشكال الحقول + قواعد التحقق) — مستقل
v2/assets/js/v2-mock-provider.js  ← التنفيذ الوحيد: بيانات تجريبية
v2/assets/js/v2-mock-data.js      ← الحزمة التجريبية
v2/assets/js/v2-netguard.js       ← يحجب أي fetch/XHR/WebSocket ويسجّل المحاولات
v2/assets/js/v2-views.js          ← الشاشات الثلاث
v2/assets/js/v2-app.js            ← الراوتر + الحالة (في الذاكرة فقط)
```

⛔ لا يوجد `import` لأي ملف من `assets/js/octa-*.js` (الإنتاج) — ويشترطه `npm run v2:check`.

## النشر — معاينة ثالثة مستقلة (يحتاج موافقة المالك)

| البند | القيمة |
|---|---|
| اسم Cloudflare المقترح | `octa-v2-preview` |
| الرابط المتوقع | `https://octa-v2-preview.ahmed3zz2020.workers.dev` |
| ملف الإعداد | `v2/wrangler.v2-preview.jsonc` |
| نوع النشر | أصول ثابتة فقط — **بلا worker.js** ⇒ لا `/api/*` ولا Railway ولا أسرار ولا KV ولا cron |
| التكلفة | ≈ ٠ ضمن الخطة المجانية (١٠٠ ألف طلب/يوم + أصول ثابتة) |
| ⛔ ممنوع | `octa` (الإنتاج) · `octa-preview` (المعاينة الحالية) · `octa-v2` (نسخة قديمة غير معزولة) · `wrangler-v2.jsonc` |

```bash
npm run deploy:v2     # يمرّ على الحارس أولًا ثم ينشر — لا يُنفَّذ قبل موافقة المالك
```

⛔ على هذا الفرع `npm run deploy` **موقوف** (حارس) — لأن `npm run deploy` على `main` = نشر إنتاج.
